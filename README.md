## 📌 Sobre o projeto

Este projeto foi desenvolvido com foco em prática de front-end, organização de layout e estruturação de páginas web para uma pousada.

O site apresenta:

* Página inicial atrativa
* Sessão de quartos
* Layout limpo e profissional
* Navegação simples
* Estrutura responsiva

---

* CSS3
